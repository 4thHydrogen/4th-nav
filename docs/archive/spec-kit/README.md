# Archived Spec Kit Artifacts

Spec Kit has been retired for this repository.

This directory preserves historical Spec Kit files for reference only:
- `specs/` — old feature specs, plans, tasks, research, and checklists.
- `.specify/` — old Spec Kit configuration, templates, scripts, and workflow files.
- `skills/` — old local Speckit agent skills.

These files are not active project instructions. Use `openspec/` for durable requirements going forward, and use direct edit for small everyday changes.
