## ADDED Requirements

### Requirement: 文件夹支持列表视图模式

文件夹 SHALL 支持两种子项展示模式：「图标网格」（grid）和「列表」（list）。每个文件夹可独立设置其视图模式，设置持久化到后端数据库。

#### Scenario: 新建文件夹默认使用图标网格模式
- **WHEN** 用户创建一个新文件夹
- **THEN** 该文件夹的视图模式 SHALL 为 "grid"，条目大小 SHALL 为 28px

#### Scenario: 切换文件夹为列表模式
- **WHEN** 用户将某个文件夹的视图模式从 "grid" 切换为 "list"
- **THEN** 该文件夹在折叠态和展开态均以列表形式展示子项

### Requirement: 列表模式折叠态预览

当文件夹视图模式为 "list" 且处于折叠态时，SHALL 根据文件夹尺寸和条目大小（itemSize）动态计算可显示的列表条目数，尽可能多地展示子项，放不下的子项在底部用 "..." 指示。

#### Scenario: 文件夹空间足够显示所有子项
- **WHEN** 文件夹视图模式为 "list"，折叠态，且文件夹的可用高度能容纳所有子项
- **THEN** 所有子项以「小 icon + 名称」形式逐行显示，不显示 "..."

#### Scenario: 文件夹空间不足以显示所有子项
- **WHEN** 文件夹视图模式为 "list"，折叠态，且有 5 个子项但只能显示 3 个
- **THEN** 显示前 3 个子项，底部显示 "..."，不显示第 4、5 个子项

#### Scenario: 条目大小影响可显示数量
- **WHEN** 用户通过滑块将条目大小从 28px 增大到 40px
- **THEN** 折叠态下可显示的列表条目数减少，放不下的条目被 "..." 替代

### Requirement: 列表模式展开态完整列表

当文件夹视图模式为 "list" 且处于展开态时，SHALL 以完整列表形式显示所有子项，每行一个子项，包含小 icon 和完整名称。

#### Scenario: 展开列表显示所有子项
- **WHEN** 文件夹视图模式为 "list"，处于展开态，文件夹内有 8 个子项
- **THEN** 8 个子项全部以「小 icon + 完整名称」形式显示，一行一条，列表可滚动

### Requirement: 图标模式行为不变

当文件夹视图模式为 "grid" 时，SHALL 保持与当前完全相同的渲染行为，不做任何修改。

#### Scenario: 图标模式折叠态不受影响
- **WHEN** 文件夹视图模式为 "grid"，处于折叠态
- **THEN** 文件夹显示子项的图标缩略预览，与当前行为完全一致

#### Scenario: 图标模式展开态不受影响
- **WHEN** 文件夹视图模式为 "grid"，处于展开态
- **THEN** 展开面板以图标网格形式显示子项，与当前行为完全一致
