## ADDED Requirements

### Requirement: 展开面板包含设置入口

文件夹展开面板 SHALL 在面板头部显示一个设置按钮（⚙），点击后弹出设置浮窗。

#### Scenario: 显示设置按钮
- **WHEN** 文件夹展开面板可见
- **THEN** 面板头部右侧显示设置按钮（⚙ 图标）

#### Scenario: 点击设置按钮弹出浮窗
- **WHEN** 用户点击展开面板中的 ⚙ 按钮
- **THEN** 在按钮附近弹出设置浮窗，浮窗包含视图模式切换和条目大小滑块

### Requirement: 设置浮窗支持视图模式切换

设置浮窗 SHALL 提供视图模式切换选项（「图标」和「列表」），切换后即时生效。

#### Scenario: 从图标切换到列表
- **WHEN** 当前视图模式为 "grid"，用户在设置浮窗中选择 "list"
- **THEN** 展开面板立即以列表形式渲染子项，折叠态预览也切换为列表模式

#### Scenario: 从列表切换到图标
- **WHEN** 当前视图模式为 "list"，用户在设置浮窗中选择 "grid"
- **THEN** 展开面板立即以图标网格形式渲染子项，折叠态预览恢复为图标模式

### Requirement: 设置浮窗支持条目大小滑块

设置浮窗 SHALL 提供连续滑块用于调节列表模式下的条目行高（范围 20px ~ 48px），拖动时实时更新预览。

#### Scenario: 拖动滑块实时更新预览
- **WHEN** 用户拖动条目大小滑块从 28px 到 40px
- **THEN** 展开面板中的列表项行高实时增大，折叠态预览也实时更新可显示条目数

#### Scenario: 滑块仅在列表模式下可见
- **WHEN** 当前视图模式为 "grid"
- **THEN** 条目大小滑块不显示或处于禁用状态，因为该设置仅影响列表模式

### Requirement: 设置修改即时持久化

用户修改视图模式或条目大小后，SHALL 立即将新值发送到后端 API 持久化。

#### Scenario: 切换视图模式后保存
- **WHEN** 用户在设置浮窗中将视图模式从 "grid" 切换为 "list"
- **THEN** 前端立即调用 API 将 folder_view_mode 更新为 "list"，同时更新本地状态实现即时预览

#### Scenario: 拖动滑块后保存
- **WHEN** 用户拖动条目大小滑块并释放
- **THEN** 前端调用 API 将 folder_item_size 更新为新值

### Requirement: 设置浮窗可通过点击外部关闭

用户点击设置浮窗外部区域时 SHALL 关闭浮窗，展开面板保持打开状态。

#### Scenario: 点击浮窗外部关闭浮窗
- **WHEN** 设置浮窗打开，用户点击浮窗外部（但仍在展开面板内）
- **THEN** 设置浮窗关闭，展开面板保持打开
