## MODIFIED Requirements

### Requirement: 所有尺寸使用同一套判定逻辑

系统 SHALL 对所有尺寸的元素（1×1、1×2、2×2、2×3 等）使用相同的吸附判定方式，不按尺寸编写不同的判定代码。ROW_HEIGHT 和 MARGIN SHALL 从 CSS 变量 `--row-height` 读取（而非硬编码常量），确保密度切换后吸附判定与视觉布局一致。

#### Scenario: 大尺寸文件夹拖动
- **WHEN** 用户拖动一个 2×3 文件夹，文件夹的视觉中心更接近网格位置 A 而不是当前位置 B
- **THEN** 文件夹的预放置位置切换到 A

#### Scenario: 文件夹中心恰好在中间
- **WHEN** 用户拖动一个 2×2 文件夹，文件夹的视觉中心恰好处于两个网格位置的正中间
- **THEN** 系统选择一个确定的位置（偏向数值较大的网格坐标），不产生来回跳动

#### Scenario: 密度切换后拖拽吸附正确
- **WHEN** 用户将密度从 "standard" 切换为 "compact"（--row-height 从 80px 变为 64px）
- **AND** 用户拖动一个 1×1 卡片
- **THEN** 吸附判定使用 64px 行高进行计算，与实际渲染的网格位置一致
