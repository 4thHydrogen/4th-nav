# Implementation Plan: 统一浮层系统与交互修复

**Branch**: `master` | **Date**: 2026-05-23 | **Spec**: `specs/005-unified-overlay-system/spec.md`

**Input**: Feature specification from `/specs/005-unified-overlay-system/spec.md`

## Summary

建立统一浮层基础设施（FloatingPortal + 状态机 + outside click hook），将文件夹浮窗、搜索引擎菜单和右键菜单迁移到同一系统，解决幽灵 hover、z-index 竞争和窄屏浮窗无法打开等问题。

## Implementation Phases

### Phase 1: 统一浮层基础设施 (US1)

新建 `OverlayLayer/` 目录，实现核心基础设施。

**新增文件**:
- `OverlayLayer/OverlayProvider.tsx` — 创建 `#app-overlay-root`，挂载到 App 根组件
- `OverlayLayer/FloatingPortal.tsx` — `createPortal` 到 overlay root
- `OverlayLayer/useFloatingPanel.ts` — 状态机 hook
- `OverlayLayer/useOutsidePointerDown.ts` — pointerdown capture 阶段 hook
- `OverlayLayer/placement.ts` — viewport-constrained placement 计算

**修改文件**:
- `ui/index.html` — 新增 `<div id="app-overlay-root"></div>`
- `ui/src/index.css` — 新增 z-index token: `--z-floating-overlay`, `--z-floating-menu`, `--z-floating-modal`
- `ui/src/App.tsx`（或入口）— 包裹 `<OverlayProvider>`

**核心接口**:

```ts
// useFloatingPanel
type OverlayPhase = 'closed' | 'opening' | 'open' | 'closing';

interface FloatingPanelState {
  phase: OverlayPhase;
  anchorRect: DOMRectReadOnly | null;
  instanceId: number;
}

interface UseFloatingPanelReturn {
  state: FloatingPanelState;
  open: (anchorRect: DOMRectReadOnly) => void;
  close: () => void;
  toggle: (anchorRect: DOMRectReadOnly) => void;
}
```

### Phase 2: 文件夹浮窗迁移 (US2)

将 FolderFloatingWindow 迁移到 FloatingPortal，统一状态管理。

**修改文件**:
- `stores/ui.ts` — 用 `folderOverlay` 替代 `popupPanel` + `expandedFolderId`
- `WidgetGrid/index.tsx` — 使用 `useFloatingPanel`，删除手写状态逻辑
- `FolderFloatingWindow/index.tsx` — 使用 `FloatingPortal` 包裹
- `DesktopCategorySection/index.tsx` — 从 FolderPopupPanel 迁移到 FolderFloatingWindow

**删除文件**:
- `FolderPopupPanel/index.tsx`
- `FolderPopupPanel/index.css`

**hover 泄漏处理**:
- `WidgetGrid/index.css`（或父组件）— 添加 `.overlay-open .desktop-workspace { pointer-events: none }`

### Phase 3: 搜索引擎菜单迁移 (US3)

将 SearchBar 的引擎下拉菜单迁移到 FloatingPortal。

**修改文件**:
- `SearchBar/index.tsx` — 使用 `useFloatingPanel` + `FloatingPortal`，用 `placement.ts` 计算位置
- `SearchBar/index.css` — 移除 `z-index: 9999`，移除 `position: absolute`（改由 Portal 定位）

### Phase 4: 状态清理 (US4)

整理 ui.ts 和清理旧代码。

**修改文件**:
- `stores/ui.ts` — 移除 `popupPanel` 和 `expandedFolderId`，统一为 `folderOverlay`
- 全局搜索移除 `z-index: 9999` 等硬编码
